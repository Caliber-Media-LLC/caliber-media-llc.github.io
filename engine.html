A voice command platform for PC gaming. Speak a command and CaliberEngine sends the matching key press to your game — so you can play without reaching for the keyboard or the mouse.

How it works

THREE STEPS. NO MOUSE.

Everything runs on your own PC while you play.

1 · LISTENYour microphone. Push-to-talk, or always listening — your choice.
→
2 · MATCHYour words are matched against the commands in your game's profile.
→
3 · PRESSThe right key is sent to the game, and your character can answer back.

What's in the beta

BUILT FOR REAL GAMES

Profiles per game

Each game gets its own commands, key bindings, abbreviations and quick phrases. CaliberEngine can switch profiles for you when it sees your game start.

Verified keybinds

Command sets checked against each game's real default keybinds for 27 titles, plus a general set for everything else. You can change any key.

Talk your way

Hold a key to talk, or leave it always listening. Ctrl+Shift+L starts and stops listening from anywhere. Say "mute" to pause it without touching a thing.

Health alerts

Teach it where your health bar is once, and it calls out when you drop past 75, 50 and 25 percent. It only reads screen pixels — never game memory.

Menu shortcuts

Teach it where your game's settings tabs are, then say "controls" or "graphics" to jump straight there.

Character voices

Pick a voice pack and your commands get answered in character. Two demo voices come with the app; more are on the Voice page.

Install

FIVE MINUTES, START TO FINISH

  1. Download the installer
    Save CaliberEngine_Setup.exe somewhere you can find it.
  2. Run it
    Windows will ask to allow changes. If it says "Windows protected your PC," click More info, then Run anyway — the beta installer isn't code-signed yet.
  3. Choose where to install
    Pick any drive and folder with the Browse button, or keep the suggested one. Then click Install.
  4. Start CaliberEngine
    The first start takes a few seconds while the speech model loads. Pick your microphone in Settings.
  5. Say something
    Open a game profile, click Launch, and speak a command. Watch the Dashboard's Last command box to see what it heard.

Good to know: CaliberEngine sends normal Windows keyboard input. Some competitive games with strict anti-cheat may not allow any program that sends keys, so check a game's rules before using it in ranked or tournament play. We can't promise it's accepted everywhere.

Questions

QUICKANSWERS

Is it free?

The beta is free to download and use.

Does it need the internet?

No. Speech recognition runs on your PC. It keeps a local log of the commands it matched, on your machine only.

Where are my settings?

In your own user folder (%LOCALAPPDATA%\CaliberEngine), so reinstalling or moving the program to another drive doesn't touch them.

Something broke. What now?

Tell us in the community Discord — what you said, what you expected, and what happened. It helps more than you'd think.
