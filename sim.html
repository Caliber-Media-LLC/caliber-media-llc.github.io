Why sim pilots use voice

7 REASONS TO FLY WITH YOUR VOICE

  1. Every switch becomes a word

    Give a command to any key in your game's profile. Say it, and the key is pressed — no hunting the keyboard mid-flight.

  2. Key combos, not just keys

    PC Commands can press a whole key combo from one phrase — handy for sims that hide functions behind modifier keys.

  3. Starfield is ready to go

    Starfield has a command set checked against its real default keybinds. Change any key to match your setup.

  4. Build your own for any sim

    Star Citizen, Elite Dangerous, a flight sim — make a profile with your own commands and key bindings. If the game takes keyboard input, CaliberEngine can press it.

  5. Short words for long names

    Add abbreviations and quick phrases, so a short word stands in for a long command — and so terms it mishears can be fixed your way.

  6. Pause it for comms

    Use push-to-talk to keep wingmen chatter from firing commands, or say mute to pause and unmute to carry on.

  7. A ship computer that talks back

    Pick an AI voice pack and your commands get answered — like having a ship computer that actually responds.

Straight talk

WHAT TO EXPECT

  • Starfield is the only space game with a verified command set right now. For Star Citizen, Elite Dangerous or a flight sim, you set up the profile and keys yourself.
  • CaliberEngine sends keyboard keys. It doesn't move joystick or throttle axes.
  • Speech recognition is English only, on Windows 10 and 11. A noisy room or a poor microphone can make it mishear you — push-to-talk helps.
  • If a game runs as administrator, run CaliberEngine as administrator too, or Windows won't let it send keys.
  • The characters are Caliber Media originals. The voices are AI-generated with ElevenLabs from our own scripts.
  • It's a beta. Tell us in the Discord which sim you want a ready-made profile for.
